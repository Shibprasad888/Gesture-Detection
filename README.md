# Hand Gesture Recognition System

A simple, modular camera engine for real-time hand gesture recognition.

## Project Description

This project includes a camera wrapper and a main application to display webcam feed with FPS and resolution overlays.

## Installation

1. Create a Python 3.12+ virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

## How to Run

Run the application from the project root:

```bash
python main.py
```

## Keyboard Controls

- Press `Q` to quit the application.
